01 — LLM agents · Deployment

Live on Hugging Face Spaces

Community AI MCP Dashboard

An agent workspace that lets a small local language model — Llama 3.2 3B via Ollama — discover and call tools through the Model Context Protocol. The challenge: make a 3B model behave like a reliable tool user, on free CPU-only hosting.

Request pipeline

User prompt Regex fast-router 60s TTL cache Llama 3.2 3B + MCP tools Truncate & filter Streaming buffer → UI

What I built

  • Regex-based fast router that skips the model entirely for obvious intents
  • Tool-name and parameter aliasing so a small model's near-miss calls still resolve
  • Result truncation and filtering to keep tool output inside the context window
  • Streaming buffer that hides raw JSON tool calls from the chat
  • Persistent typing and loading states so long tool runs never look frozen

Where it's going

On free-tier CPU hosting, multi-step tasks like summarizing a full web page are still slow. I'm profiling the pipeline end to end and working on latency next — the honest, unglamorous part of shipping local LLMs.

02 — Computer vision · Transfer learning

Master's project · RUPP, 2026

Multi-Class Fruit Classification with CNNs

A PyTorch study comparing a custom-built CNN against a transfer-learning ResNet-18 for classifying apples, bananas and oranges — the kind of model behind automated quality grading and visual checkout. Both were trained on CPU only, with no GPU acceleration.

99.2% ResNet-18 test accuracy Overall, with matching precision, recall and F1. Converged in 2–3 epochs.
96–98.5% Custom CNN accuracy Per class: apple 96.2%, orange 97.1%, banana 98.5%.
50 Epochs on CPU Batch size 16, learning rate 0.001, 80/20 train–test split.

What I built

  • FruitCNN: four conv blocks (3×3 conv, batch norm, ReLU, max-pool) into two dense layers with dropout
  • FruitResNet: frozen ImageNet ResNet-18 backbone with a new classifier head
  • Augmentation pipeline — flips, rotation, translation and color jitter — to curb overfitting
  • Evaluation with accuracy, precision, recall, F1 and confusion matrices

What I learned

The custom CNN's validation curves tracked training closely, showing the augmentation worked. ResNet-18 reached near-perfect scores in a fraction of the training — a clear case for transfer learning where labeled images are expensive. Next steps: ripeness and quality sub-classes, and edge deployment with lightweight models via ONNX Runtime.
